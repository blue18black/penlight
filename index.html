遊びかた

  • 10人のメンバーが1人ずつ登場。衣装の色に合わせると次の人が来ます
  • B:次の色へ / C:前の色へ(22色・ハロプロ公式ペンライトと同じ順番)
  • Aを2回連続で押す:今の色をメモリー。Aを1回押す:メモリーした色を呼び出し
  • Aを2秒長押し:消灯/点灯(点灯すると①REDから)
  • ゲーム中は左下のカンペを押している間、色の順番が見られます(タイムは止まりません)
  • 色を合わせたら0.5秒キープでクリア
  • キーボード:→ B / ← C / ↑ A / Shift カンペ / Space 一時停止
